# Предобработка Melbourne

Отдельная учебная работа на наборе Melbourne Housing: исследование пропусков, заполнение площади и года постройки, обработка категорий и сравнение правил поиска выбросов. Это исследовательская предобработка, не ETL-проект.

Исходный набор содержит 13 580 строк и 21 колонку. В лабораторной использовались групповые медианы и моды, отдельные признаки исправлений и ограничение экстремальных значений. Исходные цены и количество строк в обработанном наборе сохранялись. Сводка исходного выполнения приложена в `preprocessing-summary.json`.

Важно различать две задачи: для описательной лабораторной статистики рассчитаны по всему набору; для оценки модели обучаемые параметры заполнения должны вычисляться только на train. Независимый baseline в этом репозитории использует фильтр и отдельное разделение, а не выданный за тест уже обработанный целиком набор.

Правила трёх сигм, межквартильного размаха и 5–95 перцентилей дают разные границы. Отмеченное крайнее значение не обязательно ошибка: дорогой объект может быть реальной продажей. Удаление/ограничение значений требует объяснения в контексте задачи.
